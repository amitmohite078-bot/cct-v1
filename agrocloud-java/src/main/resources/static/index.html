    System Architecture & Standards

    AgroCloud AI is an IoT-free cloud advisory prototype that eliminates farm sensors and valve automation, operating purely from farmer-provided visual images and public agrometeorological weather data.

    Key Architecture Components:
    • Backend Core: Enterprise Java 21 / Spring Boot 3 running on Virtual Threads.
    • Embedded ONNX Inference: Microsoft ONNX Runtime Java with calibrated temperature scaling.
    • Agrometeorological Engine: FAO Irrigation and Drainage Paper No. 56 Penman-Monteith standard.
    • Public Weather Source: Open-Meteo Global Agrometeorological Model (CC-BY 4.0 / ODbL).
    • Privacy & Provenance: SHA-256 image digests, zero user photo retention, coordinate blurring (~1.1 km).
